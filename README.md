# Skylark Drone Operations Coordinator AI

## Overview

Skylark Drone Operations Coordinator is an intelligent, AI-powered management system designed to optimize drone fleet and pilot resource allocation. Leveraging Google Sheets for data management and Google's Gemini AI for smart decision-making, this application provides real-time insights, conflict resolution, and strategic recommendations for drone operations.

![Drone Operations Dashboard](screenshot.png)

## 🌟 Key Features

- **Intelligent Resource Allocation**
  - AI-driven pilot and drone matching
  - Smart assignment recommendations
  - Conflict detection and resolution

- **Real-Time Data Management**
  - Live integration with Google Sheets
  - Automatic status updates
  - Comprehensive fleet and pilot tracking

- **Advanced AI Analysis**
  - Context-aware decision making
  - Emergency response recommendations
  - Strategic mission planning

## 🛠 Technology Stack

- **Backend**: 
  - Python (Flask)
  - Google Generative AI
  - Google Sheets API
  - gspread

- **Frontend**:
  - HTML5
  - CSS3
  - Vanilla JavaScript

- **AI & Data Processing**:
  - Gemini Pro
  - Google Cloud Services

## 📋 Prerequisites

- Python 3.9+
- Google Cloud Project
- Gemini API Key
- Google Sheets with predefined structure
